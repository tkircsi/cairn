# Security policy

## Supported versions

Security updates are provided for `main`. There are no tagged releases yet.

## Reporting a vulnerability

Please **do not** file a public issue.

- GitHub: use **Security → Report a vulnerability** on this repository, once it is public.
- Or email: tkircsi@gmail.com

You will receive an acknowledgement. We will assess the report and, if
confirmed, ship a fix and credit you unless you ask otherwise.
